**`01b` · PhysioNet 2019 (reduced 33-feature models; matched stratum = stay ≥ 8 h, onset ≥ 4 h, not censored):**

- Cost of dropping GCS / urine / PF ratio on MIMIC VAL: softmax −0.012, sigmoid −0.019, KA −0.011.
- **MIMIC → set A (same hospital, BIDMC): 0.70; MIMIC → set B (Emory): 0.69** (softmax, matched). Drop ≈ 0.08–0.10 for every model; KA drops most on set B (0.67).

In PhysioNet the label is strongly tied to time in stay (Challenge excluded onset < 4 h; 51 % of MIMIC septic stays have onset < 4 h, vs PhysioNet early-onset 19–26 %). That is the leading explanation for the asymmetric shift.
- External calibration: source-calibrated in-the-large −0.5 to −1.8, slope 0.66–0.83.
